demo：https://ylt-blog.vercel.app/
github：https://github.com/Laliter/ylt-blog.git

个人制作：

```bash
# 1. 克隆
git clone https://github.com/Laliter/ylt-blog.git
cd ylt-blog

# 2. 删除关联
rm -rf .git

# 3. 初始化成自己的仓库
git init
git add .
git commit -m "Initial blog"

# 4. 在 GitHub 新建空仓库，然后关联
git branch -M main
git remote add origin https://github.com/用户名/仓库名.git
git push -u origin main

# 5. 本地启动
npm install
npm run dev
```

之后修改个人信息、头像和文章，再正常提交：

```bash
git add .
git commit -m "Update blog"
git push
```

让她直接用网页部署，不需要命令行：
1. 打开 Vercel。
2. 点击 Continue with GitHub，授权登录。
3. 点击 Add New → Project。
4. 找到她刚创建的博客仓库，点击 Import。
5. 页面里的配置基本都不要改：
   - Root Directory：./
   - Environment Variables：不填
   - Node.js Version：选择 22.x
6. 点击 Deploy。
7. 等待构建完成，Vercel 会给她一个类似下面的网址：
https://她的项目名.vercel.app
以后她只需要：

```bash
git add .
git commit -m "Update blog"
git push
```

推送成功后，Vercel 会自动更新网站，不需要再次手动部署。
